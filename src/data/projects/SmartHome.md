# Smart Home Dashboard

## Overview

**Smart Home Dashboard** is an interactive web application designed to provide users with a centralized platform to monitor and control their smart home devices. Leveraging IoT technology, this application enhances home automation and user convenience.

## Key Features

| Feature               | Description                                                  |
|-----------------------|--------------------------------------------------------------|
| Device Management     | Add, remove, and manage various smart devices.              |
| Real-Time Monitoring   | Receive real-time updates on device status and energy consumption. |
| Custom Automation     | Set up automation rules based on user-defined conditions.    |
| User Authentication   | Secure user accounts with authentication and authorization features. |
| Mobile Responsiveness | Access the dashboard from any device for a seamless experience. |

## Technologies Used

- **Frontend**: JavaScript, React, CSS
- **Backend**: Node.js
- **Communication**: MQTT for IoT device communication
